VIVE VILLAVO — MVP 0.1
========================

QUÉ INCLUYE
- Interfaz adaptable a celulares.
- Búsqueda y filtros por categoría.
- Formulario de propuesta de actividades.
- Guardado local de propuestas en el navegador del dispositivo.
- Archivos iniciales para instalar como PWA cuando esté alojada en HTTPS.

QUÉ NO INCLUYE (IMPORTANTE)
- No está publicada en internet ni en Google Play / App Store.
- No hay base de datos central ni panel de administración.
- Las tarjetas del inicio son ejemplos visuales ficticios y están marcadas como tales.
- El formulario no envía información a ninguna persona: guarda solo en el navegador local.
- No hay integración con Instagram, Facebook, Google Maps, boleterías ni fuentes externas.
- El service worker y la instalación PWA requieren alojamiento HTTPS para funcionar de forma completa.

CÓMO PROBAR
1. Extrae el ZIP.
2. Abre index.html en un navegador moderno para probar la interfaz y el formulario local.
3. Para probar la instalación PWA real, sube los archivos a un alojamiento HTTPS compatible.
4. Antes de usar con público, sustituir tarjetas de demostración y conectar un formulario/base de datos segura.

PRÓXIMO PASO
Elegir un servicio gratuito de alojamiento desde el celular y publicar la versión de prueba. Antes de crear cuentas, revisaremos precios, límites y condiciones actuales. No compartir contraseñas ni códigos de verificación.
